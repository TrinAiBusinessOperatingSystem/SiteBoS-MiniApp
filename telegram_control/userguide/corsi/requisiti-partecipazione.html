Guida alla Partecipazione

Executive Decision Intelligence in Management Clinico — Guida di configurazione dell'ambiente di lavoro AI per tutti i partecipanti (Uni. Vita-Salute San Raffaele & Uni. Cattolica del Sacro Cuore).

Prima di Iniziare: Leggi Questo

Non serve nessuna esperienza informatica pregressa. In questa guida ti accompagniamo passo per passo nell'installazione di programmi gratuiti e nell'attivazione del tuo "kit" di lavoro personale. Ogni passaggio è spiegato per intero, incluso cosa vedrai sullo schermo.

Perché è necessario farlo prima e non durante il corso: essendo un webinar, durante la sessione live non ci sarà nessuno che può guardare il tuo schermo e aiutarti in tempo reale come accadrebbe in un'aula fisica. Ti chiediamo di completare l'attivazione con calma nei giorni prima, così arriviamo tutti pronti e dedichiamo le 7 ore al contenuto del corso, non a risolvere problemi tecnici individuali.

Tempo necessario: circa 30-45 minuti — meglio non l'ultima sera prima del corso.

Requisiti

Cosa Ti Serve Avere Pronto

  • Un computer portatile (laptop Windows oppure Mac, non un computer fisso) — necessario per svolgere le esercitazioni pratiche e portarlo con sé; non è possibile partecipare solo con smartphone o tablet.
  • Una connessione internet stabile, sia ora per scaricare i programmi sia il giorno del webinar per tutta la durata (7 ore).
  • Circa 15-20 minuti liberi, senza fretta, per seguire questa guida con calma.
  • Abbonamenti base minimi per i due strumenti AI del corso:
    • Google Antigravity IDE: account Google con piano base minimo AI attivo (es. Google One AI Premium con Gemini Advanced o tier API abilitato).
    • Claude Code (Terminale): account Anthropic con abbonamento base minimo (piano Claude Pro oppure account console Anthropic con credito prepagato minimo di $5–$10).
Attivazione

I 7 Passi da Completare

1

Installare Python

Python è il "motore" che fa funzionare uno degli strumenti del corso — non dovrai scrivere codice tu.

  1. Vai su python.org/downloads e clicca il pulsante giallo "Download Python 3.x.x".
  2. Apri il file scaricato e segui la procedura guidata.
  3. Su Windows: nella prima schermata spunta "Add python.exe to PATH" prima di cliccare "Install Now".
2

Installare Git

Git serve per scaricare ("clonare") il kit di lavoro del corso da un archivio online pubblico del corso.

  1. Vai su git-scm.com/downloads e scarica la versione per il tuo sistema.
  2. Apri il file e clicca "Next"/"Avanti" lasciando le opzioni di default.
3

Aprire il Terminale

Un programma già presente sul tuo computer per dare istruzioni scrivendole. Userai solo 2-3 comandi già scritti, da copiare e incollare.

  • Su Windows: clicca Start, scrivi PowerShell, premi Invio sul risultato "Windows PowerShell".
  • Su Mac: apri Spotlight (Cmd + Barra spaziatrice), scrivi Terminale, premi Invio.
4

Scaricare il Kit del Corso

Con il messaggio di conferma iscrizione riceverai l'indirizzo del repository pubblico del corso, Clinic_Agent. È aperto da 7 giorni prima a 1 giorno dopo la data della tua edizione e non richiede né un account GitHub né un invito. Se partecipi in presenza il kit ti viene consegnato su chiavetta USB e puoi saltare questo passo.

  1. Copia l'indirizzo del repository che ricevi con la conferma (un link che termina in .git).
  2. Nel Terminale, scrivi e premi Invio:
git clone [incolla qui l'indirizzo copiato]

Al termine si crea la cartella Clinic_Agent sul tuo computer con dentro tutto il materiale del corso. Il repository viene chiuso il giorno dopo il corso, ma la tua copia resta sul tuo computer.

5

Installare Google Antigravity & Abilitare il Motore di Sistema

Google Antigravity è l'ambiente di lavoro visuale avanzato sviluppato da Google DeepMind per orchestrare agenti AI, esplorare grafi decisionali e gestire i file del kit.

  1. Scarica l'installer per Windows o Mac dal portale ufficiale: antigravity.google e completa l'installazione standard guidata.
  2. Al primo avvio, effettua il login con il tuo account Google (è richiesto l'abbonamento base minimo AI, es. Google One AI Premium con Gemini Advanced).
  3. Abilitazione rapida del motore da riga di comando: per consentire al sistema operativo e al kit di comunicare con Antigravity, apri PowerShell (su Windows) o il Terminale (su Mac) e incolla questo comando:
    Su Windows (in Windows PowerShell): 
    irm https://antigravity.google/install.ps1 | iex
    Su Mac (nel Terminale): 
    curl -fsSL https://antigravity.google/install.sh | bash
  4. In Antigravity seleziona "Open Folder" / "Apri Cartella" e scegli la cartella del kit scaricata al Passo 4.
6

Installare Node.js

Un programma motore essenziale per consentire l'esecuzione dell'assistente da terminale Claude Code.

  1. Vai su nodejs.org e clicca il pulsante "LTS".
  2. Apri il file e clicca "Next"/"Avanti" lasciando le opzioni di default.
7

Installare Claude Code come Terminale e Attivare il Kit

Claude Code opera come terminale agentico intelligente integrato per interrogare dati, eseguire skill e produrre simulazioni in italiano senza scrivere codice.

  1. Nel Terminale (oppure nel terminale integrato di Antigravity IDE), scrivi e premi Invio: 
    npm install -g @anthropic-ai/claude-code
  2. Entra nella cartella del kit: 
    cd [nome della cartella creata al Passo 4]
  3. Avvia l'assistente agentico da terminale: 
    claude
    La prima volta ti chiederà di autenticare il tuo account Anthropic (è richiesto l'abbonamento base minimo Claude Pro oppure account console Anthropic con credito prepagato di $5–$10). Segui le istruzioni nel browser per completare l'accesso.
  4. Quando è pronto, scrivi nel terminale in italiano: "Che skill hai disponibili in questa cartella?" — se tutto è andato bene, ti elencherà le skill operative del kit didattico.

Guida ufficiale completa: docs.claude.com/en/docs/claude-code

Checklist Finale — Sei Pronto Se

  • Hai installato Python
  • Hai installato Git
  • Sai come aprire il Terminale sul tuo computer
  • Hai scaricato il kit con git clone senza errori
  • Hai installato Google Antigravity IDE (con abbonamento base minimo) e aperto la cartella del kit
  • Hai installato Node.js
  • Hai installato Claude Code come terminale (con abbonamento base minimo) e ricevuto risposta chiedendo "che skill hai disponibili"

Tutti e 7 i punti spuntati? Sei pronto per il laboratorio. Anche solo uno non funziona? Non insistere da solo — scrivici nel canale Discord di supporto sotto: è normalissimo e lo risolviamo insieme prima della giornata.

FAQ

Qualcosa Non Funziona?

"Il comando 'git' (o 'python', 'npm', 'claude') non è riconosciuto"

Probabilmente l'installazione non si è completata, oppure serve riavviare il Terminale (o il computer). Chiudi e riapri il Terminale e riprova; se persiste, scrivici.

Compare «repository not found» o ti viene chiesta una password durante git clone

Il repository è pubblico e non richiede account, ma è aperto solo da 7 giorni prima a 1 giorno dopo la tua edizione: controlla di aver copiato l'indirizzo per intero e, se sei fuori da quel periodo o il problema resta, scrivici.

Ti sei perso a metà

Va benissimo, scrivici indicando a che punto ti sei fermato — ti guidiamo noi.
