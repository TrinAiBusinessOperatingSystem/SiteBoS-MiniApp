Guida alla Partecipazione

Executive Decision Intelligence in Management Clinico — Guida di configurazione dell'ambiente di lavoro AI per tutti i partecipanti (Uni. Vita-Salute San Raffaele & Uni. Cattolica del Sacro Cuore).

Prima di Iniziare: Leggi Questo

Non serve nessuna esperienza informatica pregressa. In questa guida ti accompagniamo passo per passo nell'installazione di programmi gratuiti e nell'attivazione del tuo "kit" di lavoro personale. Ogni passaggio è spiegato per intero, incluso cosa vedrai sullo schermo.

Perché è necessario farlo prima e non durante il corso: essendo un webinar, durante la sessione live non ci sarà nessuno che può guardare il tuo schermo e aiutarti in tempo reale come accadrebbe in un'aula fisica. Ti chiediamo di completare l'attivazione con calma nei giorni prima, così arriviamo tutti pronti e dedichiamo le 7 ore al contenuto del corso, non a risolvere problemi tecnici individuali.

Tempo necessario: circa 30-45 minuti — meglio non l'ultima sera prima del corso.

Requisiti

Cosa Ti Serve Avere Pronto

  • Un computer portatile (laptop Windows oppure Mac, non un computer fisso) — necessario per svolgere le esercitazioni pratiche e portarlo con sé; non è possibile partecipare solo con smartphone o tablet.
  • Una connessione internet stabile, sia ora per scaricare i programmi sia il giorno del webinar per tutta la durata (7 ore).
  • Circa 15-20 minuti liberi, senza fretta, per seguire questa guida con calma.

Non ti serve nessuna carta di credito: tutti i programmi che installerai sono gratuiti.

Attivazione

I 6 Passi da Completare

1

Installare Python

Python è il "motore" che fa funzionare uno degli strumenti del corso — non dovrai scrivere codice tu.

  1. Vai su python.org/downloads e clicca il pulsante giallo "Download Python 3.x.x".
  2. Apri il file scaricato e segui la procedura guidata.
  3. Su Windows: nella prima schermata spunta "Add python.exe to PATH" prima di cliccare "Install Now".
2

Installare Git

Git serve per scaricare ("clonare") il kit di lavoro del corso da un archivio online privato.

  1. Vai su git-scm.com/downloads e scarica la versione per il tuo sistema.
  2. Apri il file e clicca "Next"/"Avanti" lasciando le opzioni di default.
3

Aprire il Terminale

Un programma già presente sul tuo computer per dare istruzioni scrivendole. Userai solo 2-3 comandi già scritti, da copiare e incollare.

  • Su Windows: clicca Start, scrivi PowerShell, premi Invio sul risultato "Windows PowerShell".
  • Su Mac: apri Spotlight (Cmd + Barra spaziatrice), scrivi Terminale, premi Invio.
4

Scaricare il Kit del Corso

Riceverai, con il messaggio di conferma iscrizione, un link di invito a una repository privata su GitHub.

  1. Segui il link di invito e accetta l'accesso (se non hai un account GitHub te ne verrà chiesto di crearne uno gratuito).
  2. Copia l'indirizzo della repository (pulsante verde "Code" sulla pagina, un link che termina in .git).
  3. Nel Terminale, scrivi e premi Invio:
git clone [incolla qui l'indirizzo copiato]

Al termine si crea una nuova cartella sul tuo computer con dentro tutto il materiale del corso.

5

Installare Node.js

Un altro programma "motore", necessario per l'assistente AI del passo successivo.

  1. Vai su nodejs.org e clicca il pulsante "LTS".
  2. Apri il file e clicca "Next"/"Avanti" lasciando le opzioni di default.
6

Installare Claude Code e Attivare il Kit

Claude Code è il programma con cui interagirai durante il corso ponendo domande in italiano, senza scrivere codice.

  1. Nel Terminale, scrivi e premi Invio: 
    npm install -g @anthropic-ai/claude-code
  2. Al termine, "entra" nella cartella del kit: 
    cd [nome della cartella creata al Passo 4]
  3. Avvia l'assistente: 
    claude
    La prima volta ti chiederà di accedere — segui le istruzioni a schermo.
  4. Quando è pronto, scrivi in italiano: "Che skill hai disponibili in questa cartella?" — se tutto è andato bene, ti elencherà almeno uno strumento di analisi dati.

Guida ufficiale completa: docs.claude.com/en/docs/claude-code

Checklist Finale — Sei Pronto Se

  • Hai installato Python
  • Hai installato Git
  • Sai come aprire il Terminale sul tuo computer
  • Hai scaricato il kit con git clone senza errori
  • Hai installato Node.js
  • Hai installato Claude Code e ricevuto risposta chiedendo "che skill hai disponibili"

Tutti e 6 i punti spuntati? Sei pronto per il webinar. Anche solo uno non funziona? Non insistere da solo — scrivici (sezione Supporto sotto), è normalissimo e lo risolviamo insieme prima del webinar.

FAQ

Qualcosa Non Funziona?

"Il comando 'git' (o 'python', 'npm', 'claude') non è riconosciuto"

Probabilmente l'installazione non si è completata, oppure serve riavviare il Terminale (o il computer). Chiudi e riapri il Terminale e riprova; se persiste, scrivici.

Ti viene chiesta una password durante git clone

L'accesso alla repository non è ancora attivo sul tuo account — verifica di aver accettato l'invito ricevuto via email.

Ti sei perso a metà

Va benissimo, scrivici indicando a che punto ti sei fermato — ti guidiamo noi.
